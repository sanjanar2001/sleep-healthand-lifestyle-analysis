Sleep Health and Lifestyle Analysis

📌 Project Overview

This project analyzes the relationship between lifestyle factors and sleep health. The analysis focuses on factors such as age, occupation, sleep duration, physical activity, stress level, BMI, heart rate, daily steps, and sleep disorders.

The project also includes a machine learning approach to predict sleep disorders based on lifestyle and health-related factors.

🎯 Objectives

- Analyze sleep patterns and lifestyle factors.
- Identify factors associated with sleep disorders.
- Perform data cleaning and exploratory data analysis.
- Create meaningful visualizations.
- Build a machine learning model for sleep disorder prediction.
- Develop an interactive dashboard to present key insights.

🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Power BI

🔍 Data Analysis

The project includes:

- Data cleaning
- Handling missing values
- Exploratory Data Analysis (EDA)
- Data visualization
- Feature encoding
- Correlation analysis
- Model training and evaluation

🎯 Target Variable

Sleep Disorder

The dataset contains sleep disorder categories such as:

- Sleep Apnea
- Insomnia

🤖 Machine Learning

Machine learning classification techniques are used to predict whether a person may have a sleep disorder based on available lifestyle and health-related features.

The models are evaluated using:

- Accuracy
- Confusion Matrix
- Classification Report

📊 Dashboard

An interactive Power BI dashboard was created to display important sleep and lifestyle insights using charts, filters, and KPI cards.

💡 Key Insights

The analysis helps understand how factors such as sleep duration, stress level, physical activity, BMI, and lifestyle habits are related to sleep health.
